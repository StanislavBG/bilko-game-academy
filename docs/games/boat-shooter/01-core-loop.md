# Core Loop

## Run structure

- **Discrete stages with bosses.** 15 stages in a 3-act campaign:
  - **Act I — The Sunlit Delta** (stages 1–5)
  - **Act II — The Cursed Fog** (stages 6–10)
  - **Act III — The Volcanic Reach** (stages 11–15)
- Between acts: a **safe-harbor hub** for spending gems and changing cosmetics.
- Each stage is **3–5 minutes** of active play.
- **Weapon stack carries over through the entire campaign.** One run = one
  long build. Die = campaign over; gems and meta upgrades persist. Classic
  roguelite.

## Expected run length

- Full campaign clear (skilled): ~30 minutes.
- Average run at Normal: 40–50 minutes.
- Weekly Challenge: single seeded run with modifiers (same structure, same length).

## In-stage beats

1. **Wave phase.** Enemies spawn in waves keyed to the stage's spawn table.
2. **Mid-stage merchant.** Around 90 s in, a **Shipwright Cove** hut drifts
   into view on the bank. Shop for 15 s while combat continues.
3. **More waves.**
4. **Shipwright Chest chance** (mini-boss + boss stages only).
5. **Boss fight.** Named boss with 2–4 phases.
6. **Stage-end Cove.** Full-screen safe-haven scene. Spend coins on
   weapons/passives/rerolls; spend gems on permanent meta upgrades;
   open the Shipwright Chest; change cosmetics; hit "Set Sail" to continue.

## Level-up rhythm

- Target **3–5 level-ups per stage**, rising into Act III as enemy density grows.
- On level-up: brief pause + 3 picks (weapon / passive / stat boost / heal).

## Difficulty

- **Easy / Normal / Hard** selectable at campaign start.
- **NG+** unlocks after first clear on any difficulty. Remixes enemy
  placements, adds new drops, raises difficulty cap. Leaderboards split by mode.

## Campaign death

- Die during a run → campaign ends.
- Keep all Gems + meta upgrades; **lose** weapon stack + in-run coins.
- Restart from stage 1 next run.
- No mid-run checkpoints in v1. (May be added later behind an optional
  difficulty modifier.)
