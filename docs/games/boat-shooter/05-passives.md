# Passives — 8 total

Rules: **6 passive slots active per run.** Passives provide stat mods,
triggered effects, or serve as the evolution key for a specific weapon.
Acquire via level-up picks or merchant stock.

## P1. Crow's Nest — global damage
- **Type:** stat-mod (multiplicative global damage).
- **Fantasy:** a lookout spots weak points.
- **Curve:** L1 +10%, L2 +18%, L3 +25%, L4 +32%, L5 +40% all-weapon damage.
- **Evo key for:** W5 Flamethrower (→ Inferno Breath).

## P2. Copper Hull — armor + iframes
- **Type:** flat damage-reduction + iframe duration.
- **Fantasy:** copper sheathing deflects blows.
- **Curve:**
  - L1: -1 dmg/hit (min 1), +0.1 s iframe
  - L2: same, L3 threshold
  - L3: -1 dmg/hit, +0.2 s iframe
  - L4: -2 dmg/hit, +0.3 s iframe
  - L5: -2 dmg/hit, +0.5 s iframe, 10% chance to fully negate a hit
- **Evo key for:** W10 Spinning Axes (→ Sawblade Fortress).

## P3. Storm Compass — lightning scalar
- **Type:** element-scalar (lightning) + chain-synergy.
- **Fantasy:** a storm follows the boat.
- **Curve:**
  - L1: +15% lightning dmg, +1 chain target
  - L2: +25%, +1 chain
  - L3: +35%, +2 chains
  - L4: +50%, +3 chains, 10% any-weapon-hit chance to chain
  - L5: +65%, +4 chains, 20% any-weapon-hit chance to auto-chain
- **Evo key for:** W4 Chain Lightning (→ Tempest Cannonade).

## P4. Powder Barrel — explosive scalar
- **Type:** element-scalar (explosive) + radius.
- **Fantasy:** extra gunpowder stored below deck.
- **Curve:**
  - L1: +15% explosive dmg, +10% blast radius
  - L2: +25%, +15% radius
  - L3: +35%, +20% radius, kills-by-explosion chain-detonate (½ dmg chain)
  - L4: +50%, +25% radius, chain dmg scales up
  - L5: +65%, +35% radius, every 10th explosion is 3× damage
- **Evo key for:** W1 Bow Cannon (→ Cannonade Supreme).

## P5. First Mate — cooldown reduction
- **Type:** global cooldown reduction.
- **Fantasy:** experienced mate keeps the crew firing in rhythm.
- **Curve:** L1 -8%, L2 -14%, L3 -20%, L4 -28%, L5 -38% CDR + next attack after level-up is instant on all weapons.
- **Evo key for:** W2 Broadside (→ Thunderclap Broadside).
- **Note:** CDR uncapped globally; stacking with Reroll meta etc. can reach very low cooldowns.

## P6. Cargo Nets — pickup & economy
- **Type:** utility (magnet + coin value).
- **Fantasy:** nets trawl behind the boat, scooping everything.
- **Curve:**
  - L1: +30% magnet, +10% coin
  - L2: +45%, +15%
  - L3: +60% magnet, +25% coin, XP orbs full-radius magnet
  - L4: +80%, +35%
  - L5: +120% magnet, +50% coin, 5% per-coin double chance
- **Evo key for:** W12 Stern Mines (→ Minefield).

## P7. Spyglass — crit
- **Type:** stat-mod (crit chance + multiplier).
- **Fantasy:** see the kill before you make it.
- **Curve:**
  - L1: +10% crit, +20% mult
  - L2: +18%, +35%
  - L3: +25%, +50%
  - L4: +35%, +75%
  - L5: +50% crit, +100% mult, crits refresh 0.2 s iframes
- **Evo key for:** W9 Kraken-Ink Cloud (→ Leviathan Ink).
- **Note:** crit uncapped; at 100%+ chance all hits are crits (reserved "super-crit" tier design post-launch).

## P8. Admiral's Flag — XP + reroll
- **Type:** utility (XP + reroll quality).
- **Fantasy:** a flag rallying the fleet.
- **Curve:**
  - L1: +15% XP, reroll -10%
  - L2: +25% XP, reroll -20%
  - L3: +40% XP, reroll -30%, reroll quality +1 tier
  - L4: +55% XP, reroll -40%, reroll quality +1
  - L5: +75% XP, reroll -50%, reroll quality +2, first reroll per stage free
- **Evo key for:** W13 Ghost-Crew Volley (→ Ghost Armada).
