# Meta Progression — 7 tracks × 10 levels

Spent with **gems** at the home-screen Meta Shop or end-of-stage Cove.
Persists across runs.

## M1. HULL (max HP)

Base 6 HP. L1–L9: +1 max HP each (→ 15 HP). **L10:** +2 + 0.5 HP/s passive
regen out of combat (17 HP + regen). Regen requires no-hit for 3 s.

## M2. ENGINE (mobility)

Base 280 px/s speed, 1200 accel. L1–L9: mix of +4–5% speed and +4–5%
accel (→ 383 px/s, 1390 accel). **L10:** +10% speed + unlocks **BURST
DASH** (double-tap direction → 200 px dash, 0.3 s iframes, 5 s cooldown).

## M3. CANNONS (offense foundation)

Base 1 dmg, 3.0 shots/s, 0 pierce.
- L1: +5% base damage
- L2: +5% base damage
- L3: +5% fire rate
- L4: +10% base damage
- L5: +10% fire rate
- L6: +10% base damage, +1 pierce on Bow Cannon
- L7: +15% fire rate
- L8: +15% base damage
- L9: +20% fire rate
- **L10:** +25% base damage + random starting passive each stage start.

## M4. CREW (crit & projectile count)

Base 10% crit, 1.5× mult.
- L1: +2% crit
- L2: +3% crit
- L3: +0.1× crit mult
- L4: +3% crit
- L5: +0.1× mult, +1 proj on Bow Cannon
- L6: +4% crit
- L7: +0.2× mult
- L8: +5% crit, +1 proj on Broadside
- L9: +0.2× mult
- **L10:** +10% crit, +0.3× mult, **+1 projectile on ALL projectile weapons.**

## M5. CARGO (pickup & economy)

Base 100 px magnet, ×1.0 coin value.
- L1: +10% magnet
- L2: +5% coin value
- L3: +15% magnet
- L4: +10% coin value
- **L5:** +20% magnet, +1 treasure map fragment per run start.
- L6: +15% coin value
- L7: +25% magnet
- L8: +20% coin value
- L9: +30% magnet
- **L10:** +50% magnet, +40% coin value, **+1 gem per stage clear.**

## M6. LUCK (rare drop shift)

Base 0 luck.
- L1: +5% luck
- L2: +5%
- L3: +10%
- **L4:** +10%, unlocks **"Lucky" Cursed Chest** variant (always drops relic, no ambush).
- L5: +15%
- L6: +15%
- **L7:** +20%, unlocks **"Fortune's Favor"** per-run buff (first chest per stage is Silver+).
- L8: +25%
- L9: +30%
- **L10:** +50% luck + guaranteed 1 Gold Chest per stage.

Luck affects: chest-tier upgrade chance, merchant rarity shift, gem drop
rate (soft), treasure map fragment rate.

## M7. REROLL (merchant & level-up quality)

Base: merchant reroll 15 coins; level-up reroll 1 free/stage.
- L1: -10% reroll cost
- L2: +1 free level-up reroll per stage (2 free/stage)
- L3: -15% reroll cost
- L4: +1 free level-up reroll per stage (3 free/stage)
- L5: reroll quality +1 tier (rare → gold)
- L6: -20% reroll cost
- L7: +1 free merchant reroll per stage
- L8: reroll quality +1 tier
- L9: -30% reroll cost
- **L10:** infinite free level-up rerolls + 2 free merchant rerolls per stage + **BANISH** (rerolled options permanently removed from drop pool for the run).
